Parte 1 — XML local

O mapa do poder

Cada cartão abaixo é um elemento <cargo titulo="…" poder="…"> do XML. A cor do selo vem do atributo poder, resolvido por um dicionário no JavaScript — vermelho para o Executivo, azul para o Legislativo.

Executivo CLASSE_PODER[poder] || "badge-legislativo" Legislativo

Levar os dados embora

O navegador gera os arquivos na hora, com Blob + URL.createObjectURL — sem servidor. O CSV sai com BOM ﻿ e separador ;, do jeito que o Excel em português abre direto, e com replace(/;/g, ",") aplicado a cada campo para nenhuma descrição quebrar as colunas.

Parte 1 — Por dentro

Do texto à árvore

O JavaScript não entende texto XML puro. O DOMParser transforma a string em um documento navegável, e a partir daí valem os mesmos seletores de sempre.

Parte 2 — fetch + JSON

Quem está na disputa

Escolha um cargo: o JavaScript dispara um fetch, espera a resposta com await, lê dados.candidatos e monta os cards. Clique em um card para virá-lo e ver as propostas — que vêm do XML da Parte 1.

pronto para consultar

Recortes locais em dados/*.json, no mesmo formato do retorno do sistema DivulgaCandContas do TSE — a abordagem de mock indicada na aula para contornar o CORS. Fonte oficial: divulgacandcontas.tse.jus.br.

Aviso acadêmico

Trabalho escolar sem vínculo com a Justiça Eleitoral, com partidos ou com campanhas. Nada aqui é recomendação de voto. As propostas exibidas são resumos editoriais escritos pelo grupo — não são transcrição literal de documento oficial.

Presidente e Governador registram programa de governo, e o resumo parte dele. Senador e deputados não registram plano de governo: nesses cards o que aparece são pautas e posições públicas, rotuladas assim.

Os números seguem a regra do TSE — majoritário usa o número do partido; senador tem 3 dígitos, deputado federal 4 e deputado estadual 5. Dois números ainda aguardam confirmação e aparecem com o selo a conferir. Para dados oficiais, consulte sempre o DivulgaCandContas.
