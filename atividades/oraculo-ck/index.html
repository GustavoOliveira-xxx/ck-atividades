    02 — Memória local

    Suas últimas consultas

    Guardadas no localStorage do seu próprio navegador. Nada sai do aparelho e nada vai para servidor nenhum — porque servidor, aqui, não existe.

    Nenhuma consulta ainda. A primeira aparece aqui assim que o Oráculo responder.

    03 — Como funciona

    Do clique à resposta

    Quatro blocos e nenhum servidor no meio. O navegador é, ao mesmo tempo, a interface e o cliente HTTP que fala com a API de IA.

    1. 01

      Usuário

      Escolhe jogo, tipo de conselho, nível e escreve a pergunta na interface.

      submit
    2. 02

      Frontend

      O JavaScript valida os campos, monta o prompt e dispara a requisição HTTP.

      fetch() + async/await
    3. 03

      API de IA

      O modelo generativo processa o prompt e devolve o texto em JSON.

      generateContent
    4. 04

      Resposta

      O front lê o JSON, formata o texto e pinta o painel — ou o erro tratado.

      render()

    Chave da API

    A aplicação é client-side: a chave fica só no seu navegador (localStorage) e é enviada direto para a API do Google. Ela nunca passa por um servidor nosso — porque não há servidor nosso.

    Onde consigo uma chave?
    1. Acesse aistudio.google.com/app/apikey com uma conta Google.
    2. Clique em Create API key e copie o valor gerado.
    3. Cole no campo acima e clique em Salvar e testar.

    Sem chave, a aplicação continua funcionando no modo demonstração, com respostas locais de exemplo — útil para apresentar sem internet.
